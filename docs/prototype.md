# 样本转运系统原型

这是毕业设计的第一版可运行原型，使用合成场景和 Python 标准库，不需要 GPU、外部服务或第三方 Python 包。它用于建立系统闭环与论文中的实现基础，**不是**真实实验室系统或完整的神经网络世界模型。

## 已实现内容

- 可配置的二维网格：障碍、站点、机器人初始位置和停靠位置。
- 样本任务生命周期：未到达 → 待分配 → 前往取样 → 运输中 → 已送达；支持释放时间和截止时间。
- 每个站点占据一个网格单元，示例中同一时刻最多一台机器人位于该单元；可设置处理时间、合成波动和暂时不可用区间。
- 两种调度：`nearest` 选择距取样点最近的空闲机器人；`world` 使用动作条件预测比较候选“机器人—样本”分配。
- 世界模型原型预测取样时间、送达时间、最终机器人位置、任务状态和预计超时；它用当前地图和状态、站点处理时间先验与已完成服务的在线均值估计站点占用，**不读取未来中断、未来随机数或仿真器内部实际剩余服务时间**。这是可解释的轻量预测基线，不是已经训练好的深度世界模型。
- 离散网格移动时，机器人不会进入当前被其他机器人占据的格子；同时检查同格和对向换边。该规则偏保守，可能出现等待或超时，不等于对实际机器人或连续空间的安全证明。
- 输出 JSON、逐事件 JSONL、样本 CSV 和可离线打开的 HTML 时间轴回放；结果目录已有同名输出时拒绝覆盖。

## 运行

在仓库根目录，使用 Python 3.11 或更高版本：

```bash
python -m unittest discover -s tests -v
python -m lab_transport compare --scenario scenarios/laboratory_demo.json --seed 42 --output runs/demo-42
```

在浏览器打开 `runs/demo-42/world/report.html` 可以拖动时间轴，查看机器人、站点状态、样本任务以及最近一次调度的候选预测。`runs/demo-42/nearest/` 是基线结果，`comparison.json` 是汇总。也可只运行一个方案：

```bash
python -m lab_transport run --scenario scenarios/laboratory_demo.json --policy world --seed 42 --output runs/world-42
```

所有任务完成时命令返回 0；参数错误、输出文件已存在或在 `max_ticks` 内未完成时返回 2。超时也会保留实际运行结果，不会当作成功。

播放控件还可使用 Node.js 进行独立检查：`node tests/test_playback.js`。它是开发验证工具，不是运行 Python 原型的必需依赖。GitHub Actions 还会在标准 CPU runner 上用无头浏览器检查页面。

一次[云端验收运行](https://github.com/lieuyimo/wm/actions/runs/42249916699)通过了 13 项 Python 测试、两种策略的示例运行及浏览器中的地图、任务和候选预测显示检查；对应 job 日志保存在 `validation/logs/`。它只验证该版本和示例范围，不代表真实环境验收。

## 示例结果与解释

仓库中的 `examples/evidence/seed42-comparison.json` 记录了示例场景的一次运行：两种策略均完成 6 个样本任务；`nearest` 为 51 个仿真步，`world` 为 55 个仿真步。它们共用同一场景和随机种子，服务时间波动按“种子、样本、取放阶段和站点”确定，使同一任务的随机抽样不因调度顺序变化。不同策略在不同时间到达站点时仍可能遇到不同的中断影响。

这只是**单场景、单种子、合成数据**的功能演示，不能据此声称预测方法普遍更优。时间单位为仿真步；平均完成时间和预测误差只对已完成任务计算，超时数还包含截止时仍未完成的任务。预测误差比较实际完成步与分配时的预测完成步。

## 当前限制和后续工作

原始网格示例的地图和业务规则为合成数据，尚未经真实实验室或导师确认。另新增[依据公开医院实地研究和导航配置的场景适配](source-backed-hospital-scenario.md)，可运行上游 ICU—实验室路网；其中双机器人和人工任务序列为明确标注的功能测试设置，非医院运行记录。原型没有真实机器人接口、数据库、用户权限或物理仿真；可临时读取公开脱敏临床数据并应遵守其许可，仓库不分发患者记录或逐条衍生时序。当前世界模型不预测其他机器人未来运动或未来新任务，也没有训练神经网络；其预测不具备安全或完备性保证。Lay2Graph 先前通过了独立上游验收，本原型目前**没有**接入 Lay2Graph。

现在还可录入样本类型、采集时间、包装和规则来源，并使用独立检查器比对有来源的具体规则；可将公开 MIMIC 演示集中单次 ICU 住院的相对采样时序作为测试输入。规则适用范围、跨机构映射和时间假设见[样本规则与公开数据说明](specimen-rules-and-public-data.md)。

后续应结合实际论文要求完善样本和站点规则、系统接口和展示，评估是否需要轻量学习模型，再开展多场景、多种子测试并据实撰写论文。系统与论文材料草稿见 `docs/thesis-system-design-draft.md`。
