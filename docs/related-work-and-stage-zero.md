# 样本转运调度：相邻研究与阶段零设计

检索与整理日期：2026-11-06。项目目标是实验室样本转运仿真；以下是研究设计和查新线索，不是已经完成的实验或已经确认的创新。对于未完整阅读的论文，明确限定在摘要和可公开取得的材料。

## 初步判断

“事件驱动”“有限计算预算”“世界状态/模型辅助重调度”和“多机器人任务分配”都已有相邻工作，不能分别或简单组合后宣称首创。值得验证的较窄问题是：**在有限且相同的在线计算预算下，行动条件的任务—机器人—站点联合预测，能否帮助一个强传统调度器有选择地评估候选恢复方案，降低动态样本转运的超时和恢复成本？**

差异不自动等于创新：先确认是否存在真实、可重复的瓶颈，再与同预算的规则、显式随机模型和仿真评估比较。如果学习模型没有带来可复现的闭环收益，应接受否定结果或调整选题。

## 可证伪的候选问题

**RQ1：** 在相同可行候选集合、相同硬约束和相同 CPU 决策预算下，使用任务—机器人—站点的动作条件预测选择恢复动作，是否优于强传统规则、同预算随机/统计模型和显式仿真？

**RQ2：** 在固定总计算预算下，预测误差、风险变化或资源异常触发的选择性预测，是否优于固定周期触发和非预测的事件触发？应分别报告触发频率、总 CPU 时间与延迟，避免将更多计算带来的收益误认为模型收益。

**RQ3：** 在工作站处理时间或通信时延发生未见分布变化时，预测质量与实际决策质量如何变化；回退能否降低损失？回退和安全检查的成本也计入预算。

候选状态至少包括机器人状态、任务生命周期、站点占用/队列、通道与资源预约、事件时间和观测延迟；动作至少覆盖任务分派、等待、改道、转交或交付预约。具体哪些状态可观测、哪些动态未知及其分布必须事前定义。学习型模型应描述动作条件下的未来，而非仅保存当前共享状态。

## 实验设计与公平性

1. **阶段 0，CPU，无模型训练。** 构造正常及可解释扰动：站点处理时间波动、站点临时不可用、机器人延迟或停止、任务突增、观测陈旧、窄通道。先验证样本队列、容量与任务完成状态的可复现性。记录强传统方法的真实失效、恢复和超时；若无明显瓶颈则重新评估选题。
2. **基线。** B0 简单规则；B1 具备资源预约、可行性约束和事件触发局部修复/全局重规划的强传统方案；B2 在 B1 的同候选集合上用历史统计或显式随机离散事件模型评估；B3 同条件下使用轻量学习型动作条件模型；B4 加入经过标定的失效检测和保守回退。具体算法尚未实现，不能把名称当成已完成对照。
3. **计算预算。** 预先规定每次决策和每场景的 CPU 墙钟预算、调用次数与超时行为；报告均值、P95/P99、超时比例、模型推理及重规划总成本。共享相同场景、候选集、安全检查和可观测信息；训练成本单独披露。对固定周期、规则事件和预测触发做消融。
4. **诊断上界。** 可在离线仿真中为每个候选动作使用受控随机源进行反事实评估；不能把事实轨迹的未来当作其他动作必然发生的未来，也不能把该信息用于在线策略。该上界只在所定义的模拟器、候选集和随机样本下成立。
5. **指标。** 报告完成率、超时率、任务时延分位数、异常恢复时间、异常停滞率、重规划次数、CPU 成本及安全/容量违规。事前定义进展、监测窗口与停滞阈值；将正常排队及已证明客观不可恢复的实例单独计数，避免混为死锁。报告成对种子结果与不确定性，不以少量试运行下结论。
6. **泛化与偏差。** 按随机种子、布局和扰动分布划分训练/验证/测试；训练期间收集多种可行动作，避免只对单个历史策略有覆盖。检查多步预测误差、概率校准与候选方案排序/闭环效用，特别记录模型看似准确但选错调度的案例。
7. **停止条件。** 若强传统基线已可稳定恢复，或离线诊断评估也不能带来有意义的收益，则不把训练世界模型当成既定目标。
