# 第二轮 CPU 反事实与故障实验数据

- `initial-tie-defect-*`：确认组以前的首个 pilot；它包含“平分默认等待”的已识别设计缺陷和不足样本时的退化区间，**不用于最终效果结论**，保留以便审计。
- `corrected-pilot-local*`：统一平分规则后的固定 pilot；运行前场景和评分未改变。
- `confirm-local*`：4 个塔尔图、4 个诊所独立确认种子的本地结果。
- `pilot-ci*` 和 `confirm-ci*`：GitHub Actions 42526090945 的原始 CPU 产物；`*-extended-summary.json` 和 `*-paired-analysis.json` 由对应 CI 原始数据以后续增加的配对汇总函数重新计算，未改变原始仿真、候选、评分或选择。后者包含完整参考与真实短期参考的配对结果。
- `*-fulltrace-local*` 和 `*-fulltrace-ci*`：补充每种策略及无故障配对的逐步状态、事件和在线候选得分；云端来自 Actions 42526962786。轨迹包含尚未释放的合成任务状态，仅供离线审计，不能作为在线输入或训练特征。
- `*-auditable-ci*`：Actions 42527473374 的最新完整逐项数据，另外保存每个候选计算 20 步评分的逐步任务状态、每个样本完整执行时刻与分配事件；工作流从这些数据重新核算评分和流转均值。

压缩 JSON 包含配置、每种策略、故障暴露、正常/故障配对、各候选预测、真实短期状态和完整分支效果；位置仅保存稳定散列键。任务和故障是仿真假设，离线参考含事后信息，不得作为在线输入。来源、代码版本、统计口径与局限见[实验报告](../../../docs/decision-value-round2-report.md)和[运行前协议](../../../docs/decision-value-round2-protocol.md)。
