# PR #18 最终机制诊断与研究停止裁决（2026-11-11）

## 最终裁决

**停止继续开展细粒度模型诊断、反事实分解及参数试探。转入本科毕业设计的系统工程实现与端到端验收。**

## 保留与放弃

**保留：**
1. 冻结 V4 条件服务事件世界模型（科研版本，未经生产认证）、公开状态特征、同状态模型前向接口；
2. Rule 作为可靠保底世界模型和调度对照；已有 CP-SAT 候选生成、合法资源限制和运动安全验证；
3. 冻结结果的可复现日志、性能结果及局限说明，作为论文“预测模块与决策模块集成及实验分析”的证据；
4. 将急诊按时数量、逾期、常规流转严格分开报告，论文不能将字典序 `judge_score` 误称为急诊按时率目标。

**停止：**
1. 不再对已看过的 5 个状态进行新模型种子、粒子数、终端长度、评分权重搜索；
2. 不再发起下一轮微观误差分解，也不以这种事后案例作模型优于规则调度的主证据；
3. 不为继续定位 `906195` 训练 V5、修改环境、扩充样本或申请 GPU；
4. 不把现有冻结 V4 当作生产已认证或企业真实业务已验证。
