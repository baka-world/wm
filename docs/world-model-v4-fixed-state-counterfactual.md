# PR #18：固定真实决策状态的冻结 V4 重复预测与条件反事实实验

**裁决：发现两类可以区分的实际问题：多数状态的蒙特卡洛候选排序不稳定；另有状态即使在八组独立预测采样下稳定，也会在相同外生条件和固定后续调度策略下选择业务结果较差的候选。但当前仍不能把后一现象唯一归因于 V4 单步预测错误。**

## 2. 实验如何保证“相同状态”和“相同外生事件”

每个状态均从原V4完整真实轨迹重放当时**实际执行过的所有派单前缀**，目标tick冻结当前合法观察、规则、候选集合。只切换用于**V4粒子服务完成事件预测**的随机键。H5前缀与公共规则终端20tick、3粒子、4候选预算、字典序任务评分均保持不变。原始seed第一次评分必须与旧归档逐粒子完全吻合，否则拒绝出结果。

实际候选后果阶段不是从模型预测模拟未来，而是重新创建**真实业务仿真器**：严格重放相同事实前缀，只在目标tick替换一项合法候选，之后所有候选均按同一个P1急诊优先规则继续调度直到tick165。真实服务时长按任务、阶段、工作站键控，复检按任务键控，跨候选共享同一外生场景。模型没有机会提前观察未来复检真值或服务时长。

因此，所称“事后更优”只表示：**在这个固定合成世界、这个固定后续P1策略下，给定有限合法候选哪一个结果最好。** 不表示未来期望收益、全局最优、也不表示原先整段V4策略继续执行时一定会得到相同结果。

## 4. 真实未来揭示的两类机制

### A. 预测抽样不稳，且业务指标可能互相冲突

**905147:0：** 两种候选都是合法急诊机器人配对。原始V4选择候选1；8组预测只有2组选择1，其他6组选择0。真实固定P1续推中：
- 候选0：急诊按时率 **0/3**、平均逾期下界 **20.67 tick/job**、常规平均受限流转 **156.67 tick**；
- 候选1：急诊按时率 **1/3**、平均逾期下界 **21.67 tick/job**、常规流转 **154.67 tick**。

这是一个关键**目标冲突**：候选1能救回一个准时急诊任务，但总体逾期下界反而多1 tick/job。原\`judge_score\`按“未完成率、逾期下界、常规流转、整体流转”字典序排序，所以它选择候选0；**它没有把按时完成率作为更高层级的排序目标**。因此不能简单称原始V4选了“错误动作”，该动作在“急诊按时率”目标上恰好更好。这是评分目标与业务评价口径不一致的直接证据。

**905585:0：** 8组V4有3组选候选1。真实固定P1续推的两种候选**急诊按时率都是1/3**，但候选1急诊逾期下界 **35.33**，候选0是 **36.67**；按冻结字典序候选1更好。先前原始整段P4/P5真实运行中曾看到一个急诊任务因此被救回，但改成相同P1后续策略后，按时数量差异消失。这揭示了**单次动作后续策略耦合**，不能把整段轨迹的不同全部归于tick0这一个动作。

**905220:41：** 四个合法候选；V4八次分成候选0四次、候选1四次。两个选择急诊按时率同为100%、逾期0，但候选0常规流转116.67，候选1是118.00。两者业务价值可以区分，但三粒子近似排序不稳定。

**905804:0：** V4八次仅三次选候选1；真实候选0/1均无急诊按时完成，但候选1平均逾期下界27.67、候选0为28.00。两者价值差距很小，微小预测分量差容易翻转动作。

### B. 预测稳定也可能选到更差的后续动作

**906195:138：** V4 **8/8次选候选0**，Rule选择候选1。在目标tick固定原始公开状态、强制候选并按相同P1继续后的实际结果：
- 候选0：急诊按时率33.33%、急诊逾期11.67、常规受限流转 **154.00 tick**；
- 候选1：急诊按时率33.33%、急诊逾期11.67、常规受限流转 **152.67 tick**。

因此，在这次固定条件下，V4**稳定地选择常规时效较差1.33 tick的候选**。这个状态不符合“只要增加采样粒子就一定会选对”的解释。它更像是**当前预测状态到任务级终端价值之间的排序错位**；但现有数据仍无法确定是V4服务概率、工作流预测动力学、终端近似还是业务评分某个环节造成。

## 5. 当前最强结论与仍未解决的问题

已用实际重复模型推理和同外生真实仿真确认：

1. **采样方差确实影响选择**：5个既定状态中4个出现不同采样下的动作翻转，前几轮观察的敏感性不是单靠删粒子诊断得来的。
2. **评分目标存在多目标冲突**：按时完成数量与逾期总量可以对同一候选给出相反偏好；不能只用一个数字宣称模型好或坏。
3. **下游策略改变了单次决策的实际后果**：固定P1后续时，一些此前观察到的急诊按时优势不再出现。
4. **存在稳定但不优的决策**：906195 8/8次不变却不符合已冻结真实后果标准，说明不能把所有问题归结为3粒子采样。

仍不能据此判断：单步V4服务事件概率是否比Rule或B2更接近真实条件概率；这些数据并未提供逐查询预测概率/标签的完整配对统计，也没有在多个独立真实外生未来下评估条件期望。因此“网络预测错了”或“价值评分器错了”的比例**不可识别**。

## 6. 下一步建议（禁止凭本轮结果调优）

先冻结这批结果，不再在同五状态上改粒子数、调权重或选择新评分口径来追求某个策略胜出。下一步如要隔离原因，可新增一个预算受限、单独冻结的实验：
- 对合法活动服务会话记录 **V4/Rule/B2逐查询条件概率**与真实一步完成事件标签，先检查事件预测校准；
- 对一个稳定但有明确业务损失差异的状态，比较固定动力学下不同终端代理的候选排名，区分单步预测信息与终端估计；
- 为评估条件期望，必须对同一**公开**状态后续采样多个真正独立、但跨候选配对的外生未来，而非沿用单一合成未来或改变先前前缀。

目前没有需要立即重新训练V4的证据。本轮裁决是**机制定位 GO，稳定增益仍 BLOCKED**。
