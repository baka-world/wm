# PR #18：冻结 V4 在急诊动态调度中收益不稳定的实证诊断

**本轮裁决：已经识别“少粒子候选排序敏感 + Rule 预测评分打平”这一可复现机制；但尚不能证明它是 V4 所有失败的唯一原因，也没有证据足以区分单步预测错误与终端价值估计错误。**

本轮只读此前两批真实 CPU 实验的既有 ZIP 证据，不运行真实仿真器、不调用 V4、不训练、不使用 GPU、不修改评分或随机种子。全程不重新选择案例。数据是仿真合成，不是迈克生物实际生产记录。

## 2. 确认的量化结果

| 指标 | 先前 12 场景 | 随后 8 场景 | 两批合计 |
|---|---:|---:|---:|
| P5 V4 多候选决策 | 179 | 119 | **298** |
| P5 删去三粒子中的任一个后，至少一次改变首选 | 17 | 8 | **25** |
| P4 Rule 多候选决策 | 178 | 117 | **295** |
| P4 同样方法改变首选 | 0 | 0 | **0** |
| 严格共享同一当前状态的 P4/P5 动作翻转 | 6 | 4 | **10** |
| 动作翻转中，P4 对两动作的非索引业务评分完全相同 | 6 | 3 | **9** |
| 动作翻转中，P5 对删去哪个粒子敏感 | 5 | 3 | **8** |

这里“删一粒子”是**固定同一批既有 3 个模拟粒子的 leave-one-out (LOO) 敏感性检查**：对每个候选，删去相同粒子编号的那一份代价记录，用剩余两个代价的平均值和**原先完全相同的字典序评分**重新选择。没有抽样新轨迹、没有重复模型推理。它测量决策脆弱性，**不能作为独立随机种子重复实验或统计显著性检验**。

各臂的多候选状态来自各自策略实际轨迹，不能把 25/298 与 0/295 的比例当作严格同状态、可直接解释模型精度优劣的因果比较。真正按同一状态配对的是上表的 10 个动作差异。

“领先幅度”指 V4 选中候选相对 Rule 所选候选，在两者首个不同的 V4 业务评分分量上占优的数值，而非最终任务的真实收益、也不是模型预测误差。不同分量分别可能是急诊迟到、急诊剩余工作量、常规迟到或常规剩余工作量，不能把它们无条件求平均。

**9/10 翻转发生在 Rule 本来就打平的候选之间，7/10 由决定性分量上仅约 1/3 tick 的预测成本差触发。** 这解释了为什么微小预测变化能够影响实际派单，却不保证实用收益。

## 4. 两个曾经改善急诊按时率的案例也存在抽样脆弱性

- **905147:tick 0**：P4 Rule 选候选0，P5 V4 选候选1；两者在 Rule 非索引业务成本上完全相同，V4 在急诊剩余时间分量领先约 **0.333 tick**。删去三个粒子中的最后一个后，V4 从候选1改回候选0。实际完整 P5 轨迹使一项急诊从 tick90（逾期）变成 tick61（按时），但这**不能证明**该按时收益会在另一组预测抽样下维持。
- **905585:tick 0**：P4 选候选0，P5 选候选1；Rule 评分打平，V4 在急诊迟到分量领先约 **0.333 tick**。三种删一情况中，只有一种继续选择候选1；另外两种会改回候选0。完整场景中 V4 比 Rule 多一个急诊任务按时完成，但相对简单 P1 的结果会出现急诊任务身份交换、没有同场景按时数量的净增加。

在原 12 组合成场景中，P4 的急诊按时数为 **9/24**、P5 为 **11/24**；逐任务配对只有 2 项由未按时变成按时。后 8 组合成场景则为 P4/P5 均 **8/15**，没有急诊任务跨越按时阈值。两批合成场景源于同一生成器，20 组不是外部独立数据或可靠的泛化功效验证。

值得明确：有两次动作翻转在 LOO 检查下没有改变，包括 **906195:138**，其后常规受限流转更差约 1.33 tick/job。这说明**不能将所有负收益归因于 3 粒子抽样噪声**；业务评分、终端状态价值的误差仍可能产生稳定但错误的选择。

## 5. 哪些原因已经被证实，哪些还没有

**已经证实：**

1. 优先级字典序导致很多候选直接落败，上一轮严格剪枝已经无损保留了所有动作。
2. 在有得选的状态里，Rule 对常规工作流排序或机器人分配经常给出完全相同的业务成本；V4 很小的未来状态代价变化可打破平局。
3. 冻结 V4 只有 3 粒子，部分实际动作翻转对删去哪一个粒子非常敏感；包括迄今出现的两个正向急诊按时案例。
4. 未来队列价值估计有已验证缺陷：完全乐观残余加和常常忽略执行先后；长终端规则续推缓解了部分案例，但代价高；固定 20 tick 是成本折中，未彻底解决。
5. 现有场景结果对简单 P1 急诊优先策略仍未显示持续优势。

**当前数据无法回答：**

- 冻结 V4 在这些被选候选上的**实际服务完成概率误差**是否较 Rule/B2 更小：本次 ZIP 保留的是每候选最终业务代价和三个粒子的分量，**没有完整的每次模型查询概率、对应真实条件事件标签和时间对齐前缀**。不能把回报差异反推出 Brier 或单步预测错误来源。
- 若在同一合法状态对未选候选执行配对的真实未来，究竟哪项动作期望更优：本次 ZIP **没有为所有未选动作保存严格同状态、同外生事件的完整反事实真实轨迹**。所以既有整场景 P4/P5 差异不能严格归因到单个动作。
- 未来状态近似误差与神经网络单步误差各自占多少：目前没有将两者隔离的实验；不能编造分解百分比。

## 6. 研究判断与下一步门槛

**当前最有证据的解释是：三粒子 Monte-Carlo 决策不稳定与大量 Rule 打平候选叠加，使 V4 容易通过极小数值差异改变实际机器人任务分配。** 有时这种选择带来真实时效改善，有时没有收益或产生常规任务损失。它揭示了工程机制，但不证明神经世界模型不可能有效。

如果下一轮要对“模型预测质量还是评分器错误”做更强判断，最小需要新增**隔离、有限、固定的决策状态测量**：按当前可观察状态冻结候选，分别记录 V4/Rule/B2 的条件事件概率和真实一步事件，做同状态多个独立模型采样种子的排序稳定性试验，再用相同外生事件对候选进行有限反事实后果评估。该实验需独立冻结协议并明示它不是当前只读审计的一部分。

本轮没有开展这类新实验，没有训练或更改模型，没有再对已看过的数据调出一个有利的预测权重。**结论不是“现在收益稳定”，而是明确定位了为何此前有限收益不足以成立：关键决策同时处在评分打平和三粒子不稳定的敏感区域。**
