# 实验室样本转运研究：任务交接

## 1. 目标与研究边界

- 研究对象：仿真环境下的实验室多机器人样本转运系统；背景是本科毕业设计。
- 暂定题目可为《基于世界模型的样本转运调度系统设计与实现》，但最终研究问题和创新点应由可复现实验证据决定。
- 最值得优先验证的候选命题：在传统规划器已保障基本安全的条件下，学习型世界模型能否预测未来调度风险，改善任务持续执行能力，并降低异常带来的停滞、超时及恢复成本。
- 不应声称世界模型已被证明优于传统方法，或能彻底解决死锁。避免将已有方法的简单拼接视为已确认的创新。
- 多机器人无碰撞与任务最终完成是不同性质；暂时不移动也不必然意味着异常停滞。路径规划内部的重复搜索、环境变化后的调度失效、以及机器人—任务—站点之间的资源等待，应分别分析。
- 关注的决策是对不同候选调度动作进行条件预测和比较，而不只是预测机器人下一步位置。例如等待或先通行、任务转交、限制新任务进入窄通道、绕行、预约交付等。

## 2. 建议的系统和研究设计

候选架构：实验室仿真环境（机器人、工作站、转运任务、动态扰动）→ 传统规划器生成满足约束的候选调度 → 预测模型评估候选方案的未来状态、停滞和延迟风险 → 安全约束检查和选择 → 仿真执行、反馈和记录。预测不可靠时可采用保守回退。

- 状态可包括机器人位置与状态、运输任务、工作站占用和有关历史；动作可包括任务分配、等待、改道、交付预约等。工作站接收容量、取放时间、机器人负载和任务优先级等约束应按实际研究设定明确建模。
- 目标可概念性地表示为最小化预期任务成本与恢复成本：`E[C_task + λ C_recovery]`；碰撞及资源容量限制独立作为硬约束。具体指标、权重与约束须在实验设计中确定。
- 优先方向 A：世界模型辅助异常停滞预测与恢复；方向 B：机器人、任务与站点联合状态的反事实预测；方向 C：预测失效时的回退；方向 D：可复现的复杂异常测试。建议以 A 为主，结合 B 的状态建模，以 C 增强可靠性，并用 D 验证。
- 必须设置合理且可解释的不确定性；若动态完全已知且确定，显式规则或约束规划可能更合适。不应为了证明学习模型有效而刻意削弱传统基线。

## 3. 分阶段验证计划

### 阶段 0：先确认问题存在

- 0 GPU，不训练模型。搭建小规模网格或图结构实验室，运行简单规则调度和具有防死锁能力的较强传统方案。
- 构造正常与异常任务序列，例如窄通道拥堵、执行延迟、动态任务插入、站点容量占用或临时变化、任务突增、机器人故障及状态信息过期。
- 确认是否存在可重复的异常停滞、恢复缓慢或明显超时；分析成因并记录强传统方案的表现。
- 如果强传统基线已足够好，不人为制造弱基线；应重新评估世界模型是否值得加入。此阶段尚未因本会话的 Action 成功而完成。

### 阶段 1：确认预测是否有决策价值

- 同一仿真状态和候选调度集合下，对比简单统计预测、轻量神经状态转移模型，以及仅用于离线诊断的仿真器真实未来信息上界。
- 真实未来信息不得用于实际在线决策。若诊断上界也无法带来明显收益，应重新考虑预测是否是主要瓶颈。
- 优先 CPU；小模型训练确有需要时再考虑 GPU。

### 阶段 2：闭环比较与泛化

| 实验组 | 建议方案 |
| --- | --- |
| B0 | 简单规则调度 |
| B1 | 强传统规划与恢复机制 |
| B2 | B1 + 简单概率预测 |
| B3 | B1 + 学习型世界模型 |
| B4 | B3 + 预测失效回退机制 |

以上均为建议方案，不是已有实验结果。各组应共用相同任务输入、扰动序列、安全规则和计算预算，并测试未见过的场景。

建议指标：任务完成率、异常停滞率、平均恢复时间、样本超时率、重规划次数、计算开销和安全违规次数。实验前须给出可操作的“异常停滞”定义，排除正常排队及客观上不可恢复的情形；阈值尚未确定。

原摘要提到可用 16 GB V100，但具体算力与时间成本尚不能在地图、机器人数量及状态表示确定前可靠估计；不必先做大型视频世界模型、复杂强化学习训练或物理级仿真。
